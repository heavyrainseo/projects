# projects
## 빅데이터프로그래밍응용 수업

### Codespace 실행  
1. **projects** Repo 선택
2. "<> Code" 버튼 - Codespaces 탭 선택
3. "Create codespace on main" 버튼 클릭

### 초기화 단계  
터미널에서 아래 명령 입력  
1. `pip install uv`
2. `uv init`
3. `uv add streamlit pandas seaborn plotly` (이후 streamlit 실행 시 생략 가능)  

### streamlit 파일 실행  
`uv run streamlit run app.py`
